# Bathhouse Page And Global Navigation

## Goal

Add a dedicated `/bathhouse` landing page based on `тз-банный-комплекс.md` and introduce a shared global top navigation so users can move between the three core routes:

- `/`
- `/invest`
- `/bathhouse`

## Direction

- Shared navigation style: understated, fixed, premium, and architectural
- Bathhouse page aesthetic: `Strategic Wellness` inside the same luxury family as the mansion and investment pages
- Core message: this is not a spa service but a private high-performance recovery asset for elite guests

## Navigation

- Fixed top bar on every page
- Brand anchor on the left: `UNO Премиальный Отдых`
- Links on the right: `Главная`, `Инвесторам`, `Банный комплекс`
- Mobile behavior: compact menu toggle with stacked links
- Visual treatment: translucent dark panel with gold borders and subtle blur

## Bathhouse Page Structure

1. Hero
   - Strategic positioning and premium recovery framing
2. Market Gap
   - Why current luxury bathhouses fail elite expectations
3. Technology Core
   - Engineering systems and physiological advantages
4. Privacy Standard
   - Zero-digital policy, guest isolation, autonomous arrival
5. Service Ecosystem
   - Business-club hospitality, gastronomy, concierge layer
6. Pricing / Monetization
   - Three premium packages and financial logic
7. Vision
   - Standardization, replication, capital appreciation
8. Contact CTA
   - Strategic partner presentation request
