# UNO Premium Leisure Homepage Redesign

## Goal

Replace the current homepage with a new `Luxury Heritage` landing page for `UNO Премиальный Отдых`, based on the project brief in `тз-главная.md` and aligned with the premium visual system from `brandbook.md`.

## Direction

- Aesthetic: `Luxury Heritage`
- Primary tone: refined, historical, status-driven
- Visual anchor: a dark museum-like canvas with gold accents, large serif headlines, and archival imagery of the mansion
- Core promise: the mansion is not just a venue, but a setting where heritage becomes a new premium leisure experience

## Page Structure

1. Hero
   - Full-screen first impression with the mansion exterior
   - H1 about English Embankment, 70
   - CTA to discover the project and request a presentation
2. Heritage
   - Historical framing of the mansion
   - Combination of narrative copy and archive imagery
3. Interiors
   - Three highlighted halls with editorial cards and photography
4. Location
   - Infographic-style benefits of the address
5. UNO Project
   - Clear articulation of `UNO Премиальный Отдых`
   - Emphasis on modern comfort inside preserved historical interiors
6. Facts
   - “Did you know?” cards for memorable storytelling
7. Contact / Presentation Request
   - Premium lead form
   - Address and private-contact framing

## Visual System

- Background: near-black obsidian
- Accent: aged gold
- Typography: high-contrast serif for display, restrained sans-serif for body
- Motion: restrained fade and rise transitions on scroll
- Composition: generous vertical spacing, framed cards, layered image overlays

## Technical Notes

- Reuse the existing React + Vite + Tailwind stack
- Keep `/invest` unchanged
- Replace only the homepage composition in `src/pages/Home.tsx`
- Use downloaded reference imagery from the provided source sites
- Keep the page mobile-first and polished on iPhone/iPad breakpoints
